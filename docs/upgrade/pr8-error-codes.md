# PR8 错误码体系收口

## 本轮目标

在已经完成 DTO / VO 收口的基础上，把接口层常用错误返回进一步统一，减少控制器和安全入口点里到处散落的硬编码状态码。

## 本轮调整

1. 新增统一错误码枚举 `ResultCode`
2. `Result` 增加按错误码直接返回的重载方法
3. 全局异常处理统一映射到参数校验失败或系统异常
4. 登录、鉴权、无权限等安全入口改为统一错误码
5. 常见业务校验失败补齐更明确的错误语义：
   - 参数缺失：`20005`
   - 未登录 / 登录失效：`20003`
   - 资源不存在：`20006`
   - 数据冲突：`20007`

## 当前错误码约定

- `20000`：成功
- `20001`：通用业务失败
- `20002`：用户名或密码错误
- `20003`：未登录、登录失效、令牌无效
- `20004`：无权限访问
- `20005`：请求参数校验失败
- `20006`：目标数据不存在
- `20007`：数据冲突
- `50000`：系统异常

## 说明

这轮只收接口层错误码，不改变现有核心业务流程，也不修改前端页面交互。后续如果要继续细分业务错误码，可以在这个枚举基础上继续扩展，而不用再回到控制器里散写整数。
