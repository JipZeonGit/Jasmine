# Jasmine
一个基于SpringBoot和VUE的花店管理系统

## 技术选型<br>
SpringBoot 2.7.8 <br>
MyBatis-Plus 3.5.2 <br>
Spring Security <br>
JWT (Json Web Token) 0.9.1 <br>
Lombok <br>
FreeMarker <br>
Fast Json 2.0.7 <br>


## 数据库<br>
Redis (On Windows) 3.0.504 <br>
MySQL 5.7.18 <br>

## 额外说明
项目在本地部署根据实际环境进行修改 application.yml 的 MySQL 和 Redis 的数据库链接以及用户名和密码等
